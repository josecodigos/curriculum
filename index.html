Sobre mim

Sou engenheiro de software formado pela Campo Real (2025), buscando soluções práticas para problemas reais – desde um rastreador veicular com ESP32 até um servidor caseiro com Ubuntu Server para pequenas automações residenciais. Atualmente sou professor no Centro Universitário Campo Real, onde ensino alunos a programar em diversas linguagens e dominar diferentes tecnologias.

O que me torna um aprendiz rápido: iniciei um projeto de rastreamento veicular, implementei um sistema embarcado com conexão via WebSocket a uma API a pedido da prefeitura de Irati. Gosto de estudar sistemas operacionais GNU/Linux e entender como os computadores funcionam em baixo nível.

Fora do código: restauro um Renault Twingo 1994 com objetivo de conseguir placa de colecionador, mantenho um home lab com Navidrome, Jellyfin, Tailscale e Nextcloud para uso próprio e estou construindo um tocador de MP3 a partir de um rádio de carro. Tudo isso me ensinou a resolver problemas de forma criativa e a nunca parar de aprender.
